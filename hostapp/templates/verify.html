How it works: the server reads your cart twice over the store's own public cart API and requires the reads to settle (same version and contents), then checks the settled cart against the fixed task with CartProof's deterministic constraint checks. Single-interface evidence; the full dual-channel browser checks run offline. Your cart is found only through your browser's session cookie - there is no way to ask about another visitor's cart. A stolen session cookie could still impersonate your session; that is a known limitation of this demo.
